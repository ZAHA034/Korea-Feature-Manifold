## 1. 목적과 범위

### 1.1 목적
대한민국의 지형, 지역별 인구·사회경제 특성, 지역 간 연결(도로·철도와 통행량)을 하나의 일관된 데이터 구조와 기하 구조로 통합하여, 다음 작업의 **공통 기준선(baseline)** 으로 쓴다.

- 정책 시뮬레이션: 교통망 신설·폐쇄, 인구 이동, 시설 배치가 국토 구조에 주는 영향
- 입지 분석: 접근성, 배후 인구, 생활권 경계 기반 후보지 평가
- 지형 분석: 산맥·하천 등 자연 장벽이 실제 이동과 생활권에 주는 영향 정량화
- 분석 프로토콜 제시: 모든 분석을 "기준선 대비 변화량"으로 표현하는 표준 절차

### 1.2 설계 원칙
1. **재현성 우선**: 같은 데이터 버전 + 같은 설정 = 같은 결과. 모든 산출물에 출처를 기록한다.
2. **측정과 모델의 분리**: 관측 데이터와 계산된 지표(거리, 곡률, 임베딩, 예측)를 다른 층에 둔다.
3. **물리 지도는 항상 기준 좌표**: 비유클리드 표현은 물리 지도에 대한 "보조 렌즈"이며, 왜곡을 함께 보고한다.
4. **한정된 연산 예산의 적응적 배분**: 정보 밀도가 높은 곳에 연산을 더 쓰되, 모든 지역에 최소 해상도를 보장한다.
5. **확장 가능한 스키마**: 새 지표·새 연도·새 공간 단위는 코드 변경 없이 데이터 추가만으로 수용한다.

### 1.3 비목표 (v1 기준)
- 실시간 교통 예측 서비스
- 개인 단위 이동 데이터 처리 (집계 데이터만 사용)
- 법적·행정적 의사결정을 대체하는 자동 판단

## 2. 핵심 개념

### 2.1 두 개의 공간
| 공간 | 좌표 | 거리의 의미 | 용도 |
|---|---|---|---|
| 물리 공간 | 경위도(x, y), 고도(z), 시간(t) | 지표면 위치 | 기준 지도, 지형 분석, 결과 표시 |
| 기능 공간 | 임베딩 좌표 (유클리드/쌍곡/혼합 곡률) | 실제 왕래·이동 비용·특성 유사도 | 생활권, 위계 구조, 중심–주변 분석 |

### 2.2 기본 객체
- **지역(노드)**: 공간 단위 하나. 특성 벡터 `x_i ∈ R^d`를 가진다.
- **연결(엣지)**: 지역 간 방향 있는 연결. 수단·통행량·통행시간을 가진다.
- **밀도장**: 지역 특성에서 유도한 연속 함수 `ρ(x)`. 연산 배분과 metric 변형에 쓰인다.
- **시나리오**: 기준선에 대한 변경 목록 (엣지 추가/제거, 속도 변경, 인구 이동 등).

## 6. 거리와 기하

### 6.1 통행시간 준거리 (graph quasi-metric)
도로·철도망을 가중 방향 그래프로 두고 최단 통행시간을 거리로 쓴다.

```
d(u, v) = min_{경로 P: u→v} Σ_{e∈P} t_e
```

- `d(u, v) ≠ d(v, u)`일 수 있다(혼잡 방향, 일방통행, 경사). 비대칭을 보존한다.
- 대칭이 필요한 알고리즘에는 `d_sym = (d(u,v) + d(v,u)) / 2`를 쓰되, 원본 비대칭 거리도 함께 저장한다.
- 시간대(`period`)별로 별도 계산한다.

### 6.2 지형 비용 metric (리만/핀슬러)
래스터 지형 위에 이동 비용 함수 `c(x)`를 정의하고, 원래 metric `g0`를 등각적으로 변형한다.

```
g(x) = c(x)² · g0
c(x) = f(경사, 토지피복, 도로 유무·속도)
```

- 측지 거리는 Fast Marching Method(`scikit-fmm`)로 계산한다.
- 오르막/내리막 비대칭을 반영하려면 방향 의존 비용(핀슬러)으로 확장한다 (v2).
- 활용: 산맥 장벽 정량화, 터널·도로 신설 시 측지선 변화.

### 6.3 쌍곡 임베딩 (푸앵카레 원판)
도시 위계(수도권 → 광역시 → 중소도시 → 군)는 트리에 가깝고, 쌍곡 공간에 적은 왜곡으로 들어간다.

```
d_P(x, y) = arcosh( 1 + 2‖x − y‖² / ((1 − ‖x‖²)(1 − ‖y‖²)) )
```

- 입력: 6.1의 거리 행렬 또는 통행량 가중 그래프
- 방법: 거리 보존 손실을 리만 최적화로 최소화 (`geoopt`의 PoincareBall)
- 배치 해석: 중심 = 높은 위계·허브, 가장자리 = 하위 지역. 가장자리의 지수적 면적 증가가 세분 단위를 수용한다.
- 확장: 쌍곡 × 구면 × 유클리드 곱공간 임베딩으로 위계와 순환 구조를 동시에 표현 (v2)

### 6.4 이산 곡률
**Ollivier–Ricci 곡률** (엣지 x–y):

```
κ(x, y) = 1 − W1(m_x, m_y) / d(x, y)
m_x = α·δ_x + (1 − α)·(통행량 가중 이웃 분포)
```

- `W1`: 1-Wasserstein 거리 (`POT` 라이브러리, 또는 `GraphRicciCurvature` 패키지)
- κ ≪ 0: 두 군집을 잇는 병목 연결 → 교통망 투자 우선순위 후보
- κ > 0: 생활권 내부의 촘촘한 연결
- **Ricci flow**로 엣지 가중치를 반복 갱신하면 병목이 끊어지며 생활권이 자동 분리된다.
- 대규모 계산의 빠른 근사로 Forman 곡률을 함께 제공한다.

### 6.5 확산 거리 / 통근 시간 거리
그래프 라플라시안 기반으로 여러 경로의 중복성을 반영한다. 한 경로가 끊겼을 때의 회복력 분석에 쓴다.

```
commute(u, v) ∝ (e_u − e_v)ᵀ L⁺ (e_u − e_v)
```

### 6.6 왜곡 보고 (필수)
모든 임베딩 산출물에 다음을 함께 저장한다.
- 평균 상대 왜곡: `mean | d_emb − d_true | / d_true`
- 최악 왜곡 상위 20개 지역 쌍
- 그래프 재구성 지표(mean average precision)

## 7. 밀도 적응 연산

### 7.1 개념
연산 예산(격자 칸 수, 샘플 수, 계산 쌍 수)을 고정하고, 이를 공간에 균등 배분하는 대신 **정보 밀도**에 따라 재분배한다. 목적은 같은 연산량으로 오차를 줄이는 것이다.

### 7.2 정보 밀도 정의
인구밀도만으로 정하지 않는다. 인구가 적어도 변화가 큰 지역이 정책적으로 중요할 수 있기 때문이다.

```
w_i = λ1·norm(인구·통행 밀도_i)
    + λ2·norm(특성 변화율_i)        # 인구 감소율, 고령화 속도 등
    + λ3·norm(국지 분산_i)          # 하위 단위 간 특성 이질성
    + λ4·norm(모델 오차_i)          # 이전 실행의 예측 오차 (반복 정제 시)
```

`λ`는 설정 파일의 공식 파라미터이며 실행 기록에 남긴다.

### 7.3 배분 규칙 (형평 하한 포함)

```
n_i = max( n_min,  N · w_i^α / Σ_j w_j^α )   이후 Σ n_i = N 이 되도록 재정규화
```

| 파라미터 | 의미 | 권장 초기값 |
|---|---|---|
| N | 총 연산 예산 | 실험별 지정 |
| α | 0이면 균등, 1이면 밀도 비례 | 0.5 |
| n_min | 지역당 최소 해상도 | 모든 시군구에 최소 1단위 이상 |

> 하한이 없으면 모델이 밀집 지역만 정밀해지고 저밀도 지역은 뭉개지는 자기강화 편향이 생긴다. 지역 균형 정책의 기준선으로 쓰려면 하한은 필수다.

### 7.4 밀도를 metric으로 통합
밀도를 별도 가중치가 아니라 metric 변형으로 넣으면, 변형된 공간에서 균등 샘플링하는 것만으로 원래 지도의 적응 샘플링이 된다.

```
g_ρ(x) = ρ(x)^β · g0
```

이는 6.2의 지형 비용 metric과 같은 형식이므로, 두 변형을 곱해 하나의 metric으로 다룰 수 있다.

### 7.5 연산 절감 장치
| 장치 | 내용 | 효과 |
|---|---|---|
| 계층 격자 세분화 | H3 계층에서 `w_i`가 큰 칸부터 분할 (예산 N 내) | 같은 칸 수로 오차 감소 |
| 원거리 근사 | 중력모형 등 쌍별 계산에 Barnes–Hut 방식 적용 (개방각 θ) | O(N²) → O(N log N) |
| 희소 OD | 통행량 누적 상위 p%(예: 95%)를 덮는 연결만 정밀 유지, 나머지 집계 | 엣지 수 대폭 감소 |
| 가중 샘플링 | GNN 학습 시 통행량 비례 노드·이웃 샘플링 | 같은 학습 비용으로 핵심 구조 학습 |
| 다중 속도 갱신 | 변화가 빠른 지역은 짧은 시간 간격으로 갱신 | 시뮬레이션 비용 감소 |
| 쌍곡 다해상도 | 원판 중심에 거친 단위, 바깥에 세분 단위 배치 | 가변 깊이 계층을 자연스럽게 수용 |

## 13. 리스크와 열린 질문

**리스크**
- OD 데이터 접근: 지역 간 통행량은 신청·승인이 필요할 수 있다. 대안으로 중력모형 추정 OD를 임시 사용하고 명시한다.
- 공간 단위 문제(MAUP): 단위에 따라 결론이 바뀔 수 있다. 핵심 결과는 두 개 이상의 단위로 교차 확인한다.
- 행정구역 변경: 대응표 누락 시 시계열이 깨진다.
- 임베딩 오해: 비전문가가 원판 위 거리를 실제 거리로 오해할 수 있다. 물리 지도를 기본 화면으로 둔다.
- 밀도 편향: 7.3의 하한 없이 쓰면 저밀도 지역 분석 품질이 떨어진다.

**열린 질문**
- 기준 공간 단위: 시군구로 시작하되, 읍면동/H3 확장 시점은?
- 기준 연도: 최신 OD 데이터 연도에 맞출 것인가?
- 철도·대중교통을 v1에 포함할 것인가, 도로만으로 시작할 것인가?
- 정보 밀도 가중치 `λ`를 분석 목적별 프리셋으로 둘 것인가?

## 부록 A. 용어

| 용어 | 뜻 |
|---|---|
| 준거리(quasi-metric) | 대칭성이 없는 거리. A→B와 B→A가 다를 수 있음 |
| 측지선(geodesic) | 주어진 metric에서 두 점 사이 최단 경로 |
| 리만 metric | 공간 각 지점에서 거리를 재는 방식. 이동 비용으로 공간을 늘이거나 줄임 |
| 핀슬러 기하 | 방향에 따라 거리가 달라지는 일반화된 metric |
| 푸앵카레 원판 | 쌍곡 공간의 모형. 가장자리로 갈수록 면적이 지수적으로 커짐 |
| Ollivier–Ricci 곡률 | 엣지 양 끝 이웃 분포의 운송 비용으로 정의한 이산 곡률 |
| Ricci flow | 곡률에 따라 엣지 가중치를 반복 갱신해 군집 구조를 드러내는 과정 |
| MAUP | 공간 단위 설정에 따라 분석 결과가 달라지는 문제 |
| OD | 출발지–도착지(Origin–Destination) 통행량 |
| 대리 모델 | 비싼 시뮬레이션을 근사하는 학습 모델 |
