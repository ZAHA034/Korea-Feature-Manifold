# 0009-곡률·임베딩 기준 그래프와 엣지 길이

- 상태: 제안 (0S 결과를 보고 3단계 시작 전에 확정)
- 날짜: 2026-10-18
- 관련: PLAN G11, 6.1a절 0S-3·0S-5, 6.4절 3-1·3-2 / DESIGN 6.4, 6.6

## 배경
시군구 간 OD의 밀도는 자료마다 다르다. 국내인구이동(2025)은 시군구 쌍의 92%에 이동이 있어서 그대로 쓰면 이웃 분포가 전국으로 퍼져 곡률의 의미가 약해진다. 통근·통학(2020)은 쌍의 28%만 양수다. 반대로 인접 쌍만 쓰면 흐름의 상당 부분이 빠진다. 사전 계산에서 시군구 간 흐름 중 인접 쌍의 비중은 통근·통학 46%, 인구이동 32%였다. 다각형 접촉만으로 인접을 정하면 옹진·진도·울릉·거제·남해가 고립된다.

## 선택지
기준 그래프는 OD 완전 그래프, 공간 인접 그래프, OD 백본 중에서 고른다. 엣지 길이는 `d_sym`과 통행량 거리 ℓ 중에서 고른다.

## 결정
1. 기본 그래프 `G_adj`는 경계를 공유하는 지역 쌍(점 접촉 제외, 허용오차 약 50 m)에 연륙·연도교 링크와 섬 연결 링크(ADR 0007)를 더한 것이다. 교량·섬 링크는 `configs/reference/`에 둔다.
2. 민감도 그래프 `G_flow`는 통행량 상위 연결만 남긴 OD 백본이다. 백본 기준(지역별 상위 k 등)은 0S 이후에 정한다.
3. 엣지 길이는 두 그래프 모두 `d_sym`(분)이다. 그래서 두 결과의 차이는 위상에서만 나온다.
4. 이웃 분포는 m_x = α·δ_x + (1 − α)·(통행량 가중 이웃 분포)이고 기본 α = 0.5다. 가중은 KTDB OD가 기본이고 통근·통학 OD로 교차 확인한다. 인접 쌍의 흐름이 0이면 ε 가중을 준다. 0S에서는 균등 분포를 기본으로 하고 통근·통학 OD 가중 결과를 함께 본다(KTDB OD는 0S에서 쓰지 않는다).
5. 길이를 통행량 거리 ℓ(ADR 0010)로 바꾼 ORC는 선택 변형이며 `graph_kind`로 구분한다. 음곡률 엣지 검토에는 쓰지 않는다. 길이와 이웃 질량에 모두 통행량이 들어가면 곡률이 통행량 크기를 다시 표현할 뿐이기 때문이다. 합성 실험에서 길이를 통행시간과 ℓ로 했을 때 음곡률 상위 20개 엣지는 1개만 겹쳤다.
6. MAP는 `G_adj`와 `G_flow` 각각을 기준으로 보고한다.
7. ORC는 POT(`ot.emd2`)로 직접 구현한다. GraphRicciCurvature는 Windows 네이티브에서 계산할 수 없으므로 WSL2 교차 검증에만 쓴다.
8. 음곡률 엣지, 생활권 같은 핵심 결론은 `G_adj`와 `G_flow` 두 그래프에서 함께 확인하고, 다르면 차이를 보고한다.
9. 음곡률 엣지 검토의 분류 기준은 PLAN 6.1a절을 따르며, 0S 결과를 보기 전에 고정한다.
