# 0011-밀도 배분 정식화, 정수화 방식, λ 프리셋

- 상태: 제안 (4단계 시작 전 확정)
- 날짜: 2026-10-18
- 관련: PLAN G18, G19, G20, 4.1 질문 4, 6.5절 / DESIGN 7.2–7.4

## 배경
DESIGN 7.3의 "max 후 재정규화"는 하한을 다시 깨뜨릴 수 있고, 정수화 규칙과 예산 부족 처리가 없다. `norm()`도 정의되지 않았다.

## 선택지
정수화 방식은 최대 잉여법(해밀턴), Webster(Sainte-Laguë) 제수 방식, Jefferson(D'Hondt) 제수 방식 중에서 고른다.

## 결정
1. 연속 목표는 하한 고정 반복(water-filling)으로 구한다. x_i = max(n_min, c·p_i), Σ x_i = N의 유일한 해다(알고리즘은 PLAN 6.5절). N < K·n_min이면 오류다. `n_min`은 0 이상의 정수인 필수 인자이며, 0은 4단계 실험의 대조군에서만 명시해 쓴다.
2. 정수화 기본값은 최대 잉여법(해밀턴 방식)이다. 보장하는 성질:
   - Σ n_i = N
   - 하한에 고정된 지역은 n_i = n_min, 나머지는 floor(x_i) ≤ n_i ≤ ceil(x_i)
   - α = 0이면 max − min ≤ 1
   - w_i > w_j ⇒ n_i ≥ n_j, w_i = w_j ⇒ |n_i − n_j| ≤ 1
   - 입력 순서를 바꿔도 결과가 같다
3. **N 단조성은 보장하지 않으며, 의도적으로 테스트하지 않는다.**
   - 최대 잉여법에는 앨라배마 역설(N이 늘 때 일부 몫이 줄어드는 현상)이 있다. 예: w = (1, 9, 25, 25), α = 0.5, n_min = 1, N = 7 → 8이면 (1, 2, 2, 2) → (1, 1, 3, 3)이다.
   - 이 사례를 기대값 테스트로 고정해 의도된 동작임을 남긴다. 나중에 "N이 늘면 어떤 n_i도 줄지 않는다"는 테스트를 넣지 않는다.
   - x_i는 N에 단조이므로 줄어드는 폭은 지역당 1단위 이하다. 4단계 실험은 같은 N에서 방식을 비교하므로 영향이 없다.
   - w 변화에 대한 단조성(인구 역설)도 보장하지 않는다.
4. 이 선택은 정리가 강제한 것이 아니다. Balinski–Young 정리는 지역 수 K ≥ 4이고 총 단위 N ≥ K + 3일 때 몫 성질과 인구 단조성을 늘 함께 만족하는 방법이 없다는 것이다. 앨라배마 역설만 막으면서 몫 성질을 지키는 방법(Balinski–Young의 Quota method)은 있다. 단순성을 위해 최대 잉여법을 택한다.
5. N을 훑는 실험이나 w가 실행마다 바뀌는 반복 정제(λ4 > 0)가 필요해지면 n_min에서 시작하는 Webster(Sainte-Laguë) 제수 방식(`rounding: webster`)을 더한다. 이 방식은 N과 w에 단조지만 몫 성질은 보장하지 않으므로 위반 수를 보고한다. Jefferson(D'Hondt) 방식은 w가 큰 지역에 단위를 몰아주어 하한의 형평 취지와 맞지 않으므로 쓰지 않는다.
6. 부동소수 규칙:
   - region_id 순으로 정렬하고 `math.fsum`으로 합을 구한다.
   - 소수부는 1e-9 단위로 반올림해 비교하고, 동률은 w 큰 순 → region_id 순으로 정한다.
   - 반복 횟수로 오류를 내지 않는다. N = K·n_min이면 한 번 더 돌 수 있다.
   - 분수 산술 참조 구현과 비교하는 테스트를 둔다.
7. `norm()`의 기본은 백분위 순위이고, 선택지로 로그 변환 후 min-max를 둔다. 모든 w_i에 작은 양의 하한 ε을 둔다.
8. 밀도 metric과 지형 비용 metric은 별도 함수로 두고, 합성은 명시적으로 호출할 때만 허용한다.
9. λ 프리셋은 `configs/presets/density/`에 둔다(예: `equity`, `efficiency`, `change`). 실행 기록에는 프리셋 이름과 해석된 λ 값을 모두 남긴다.
