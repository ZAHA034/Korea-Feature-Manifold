# 0013-0S 판정 기준 보강: 기저율, 차수 통제, 쌍곡 반지름 상한

- 상태: 제안 (0S 첫날 채택)
- 날짜: 2026-10-18
- 관련: PLAN 6.1a 판단 기준, 3-2, 3-3, 6.4 끝 문단, 7.1 tree, ADR 0009·0010

## 배경
PLAN v0.3의 0S 판정은 세 가지가 결과를 왜곡할 수 있다.
(1) "상위 20개 중 자연 장벽 5개 이상"은 전체 인접 엣지의 산맥 횡단 비율(기저율)과 비교하지 않는다.
(2) ORC는 차수가 낮은 해안·접경·섬 엣지에서 장벽과 무관하게 음수가 되기 쉽다.
(3) 학습 척도 상대 stress는 트리형 자료에서 유한 최적해가 없어 왜곡 비가 반복 횟수에 따라 달라진다.

## 선택지
판정 유지 / 기저율·차수 통제·반지름 상한 추가(채택)

## 결정
1. 기저율 비교 (PLAN 6.1a "계속" 기준 대체)
   - p0 = G_adj 전체 엣지 중 '자연 장벽'으로 분류되는 비율 (같은 분류 규칙)
   - k = 음곡률 상위 20개 중 자연 장벽 수
   - 단측 초기하 검정 p < 0.05이면 장벽 대응 있음. "5개 이상" 고정값은 폐기
   - 보고: p0, k, 기대값 20·p0, p값
2. 차수 통제 (PLAN 3-2와 0S-3에 추가)
   - κ와 (1/deg_u + 1/deg_v)의 스피어만 상관을 보고
   - 잔차 곡률 κ̃ = κ − (κ ~ 1/deg_u + 1/deg_v + 섬링크 여부 의 OLS 적합값)
   - κ̃ 상위 20개로 1의 검정을 다시 한다
   - "계속"은 κ와 κ̃ 두 경우 모두 1을 통과해야 한다
3. DEM 보조 지표 (선택, DEM을 0S에서 확보한 경우)
   - 엣지마다 두 출발점을 잇는 선분 위 최고 고도 − 두 끝점 고도 중 큰 값 = h_e
   - κ̃와 h_e의 스피어만 상관, 엣지 순열 1,000회로 p값
   - 판정에는 쓰지 않고 1의 산맥 선 출처 의존성을 확인하는 용도
4. 쌍곡 반지름 상한 (ADR 0010 3-3 보강, PLAN 6.4 끝 문단 대체)
   - 원판 좌표의 쌍곡 반지름(원점 기준) ≤ R_max = 10, 유클리드는 같은 척도 제약 없음
   - 상한 아래에서 수렴까지 최적화: 200회 동안 상대 stress 상대 변화 < 1e-6, 최대 20,000회
   - 판정(왜곡 비 ≤ 0.8)은 수렴값으로 한다. 상한에 닿은 점 수를 함께 보고
   - 7.1 tree 판정 규약의 기준값(0.0537, 비율 0.351·0.360)은 이 설정으로 다시 계산해 고정한다

## 영향
- PLAN 대체 절: 6.1a 판단 기준(계속 조건), 3-2(차수 보고), 3-3과 6.4 끝 문단(반지름 상한·수렴 기준), 7.1 tree 기준값
- 코드·데이터: 0S 노트북에 기저율·κ̃ 계산 추가. embedding_distortion에 converged, n_iter 컬럼 추가
- PLAN 변경 이력: "0.3 동결" 행과 "ADR 0013" 행 추가
