# 0S 사전 검증: 판정 규칙의 합성 자료 점검 (2026-10-18)

> S1 채택 커밋 전에 읽는다. 합성 자료로만 계산했고 실데이터는 쓰지 않았다. 스크립트와 전체 결과는 `C:\dev\kfm-data\0S-prereg\`(git 밖, `bar/`, `rcap/`, `results_full.md`)에 있다.

## 요약

1. 균등 이웃 분포와 엣지 길이 `d_sym`(통행시간)에서 장벽은 그것을 건너는 엣지의 κ를 음수가 아니라 **양수 쪽으로** 민다. 그래서 ADR 0013 1·2·5항의 "음곡률 상위 20개 중 장벽 엣지" 검정은 검정력이 거의 없다(합성 지도에서 0–0.44). 채택 전에 재검토해야 한다.
2. 반지름 상한은 효과가 있다. 다만 R_max = 10과 Adam 단독 수렴 규칙을 함께 쓰면 수렴하지 않거나 진동하는 지점에서 멈출 위험이 크다. 권장안은 R_max = 5에 L-BFGS-B 마무리 단계를 더하는 것이다.

## 1. 장벽과 곡률 (ADR 0013 1·2·5항)

| 확인 | 결과 |
|---|---|
| 장벽이 건너는 엣지를 더 음수로 만드는가(균등 분포, `d_sym` 길이) | 아니다. 건너는 엣지의 Δκ는 +0.03 ~ +0.13이다(건너는 통행시간 +14% ~ +141%). 벌칙이 커지면 κ → (1 − α)(c_x/deg_x + c_y/deg_y) > 0이 된다(해석해). 길이 d가 W1보다 빨리 커지기 때문이다 |
| 음의 신호는 어디로 가는가 | 건너는 엣지와 끝점을 공유하는 옆 엣지로 간다(Δκ −0.01 ~ −0.06) |
| OD 가중에서는 | 건너는 엣지가 음수가 되지만, 길이 때문이 아니라 장벽이 통행량을 줄이기 때문이다. 통행시간 효과 없이 산지 인구가 적기만 해도 같은 신호가 나온다(거짓 양성 0.15–0.88) |
| 차수 효과 | 전체적으로는 차수가 낮을수록 κ가 양수다(ρ +0.18). 다만 균등 분포의 음곡률 상위 20개에는 해안 엣지가 많다(0.39, 전체는 0.19) |
| OLS 잔차로 다시 고르기 | 혼입이 사라지지 않는다. 상위 20개의 해안 비율이 0.39에서 0.48–0.50으로 오히려 오른다 |
| 판정 규칙 성능(합성 지도 100개) | "상위 20개 중 5개 이상"은 검정력 0.00–0.02, 초기하·잔차 방식은 0.44 이하. 실제 산맥 선의 기저율이 15–25%면 "5개 이상"은 우연만으로 16–59% 통과한다 |
| 기준 차분 곡률 검정(권장) | κ_ex = κ(`d_sym`) − κ_geo. κ_geo는 같은 그래프·α·이웃 분포에서 인접 엣지 길이만 직선 거리 × median(`d_sym`/직선 거리)로 바꾼 곡률이다(교량·섬 링크는 `d_sym` 유지). 검정은 Spearman(κ_ex, 평균 경사 s) 단측 ρ > 0이며, 단순 p와 시도 하나씩 빼는 jackknife p가 모두 0.05 미만이어야 통과한다. 거짓 양성 0.00–0.02, 검정력 0.89–0.90(건너는 통행시간 +12–14%), +24%부터 1.00. 차수·해안·길이와의 상관 \|ρ\| ≤ 0.013 |
| DEM | 90 m면 충분하다(250 m 블록 평균, 250 m 간격 표본). 누적 상승고는 길이에 좌우되므로(ρ 0.86) 쓰지 않는다. 초과 고도는 상위 20개 기술용으로 남긴다 |
| 산맥 선 출처 | 이진 "산맥 선 교차" 지시변수는 선 출처에 따라 결과가 바뀐다(정맥 추가 시 검정력 0.59 → 0.43) |

권장 수정(사용자 결정 사항):
- 1·2·5항의 판정 검정을 κ_ex와 평균 경사 s의 단측 순위상관(jackknife 포함)으로 바꾼다. 상위 20개 분류는 기술용으로만 둔다. 이 경우 DEM은 선택이 아니라 필수다.
- 유효성 점검으로 κ_ex와 (1/deg_u + 1/deg_v), 해안·접경 지시변수, log 직선 거리의 |ρ|가 모두 0.1 미만인지 본다. 넘으면 "조정"이다.
- PLAN 7.1에 다리 길이 fixture를 더한다. barbell 다리 길이 L에서 κ = 0.2 − 0.8/L이다(L = 1, 2, 4, 8, 32에서 −0.6, −0.2, 0, 0.1, 0.175).
- DESIGN 6.4의 "κ ≪ 0 = 병목"은 엣지 길이가 통행시간이면 성립하지 않는다는 단서를 ADR 0009를 채택할 때 단다.
- 수치는 합성 세계 기준이다. 실제 한국(터널이 많은 산악 도로, OSM 속도, 시도 단위 흐름 효과)에서의 검정력은 확인하지 않았다. 균등 분포에서 건너는 엣지가 양수 쪽으로 간다는 부호 결과는 해석해라서 합성 세계와 무관하다.

## 2. 쌍곡 반지름 상한 (ADR 0013 4항)

| 확인 | 결과 |
|---|---|
| 상한이 없으면 | 트리 왜곡 중앙값이 반복 수에 따라 계속 준다(2천 회 0.0537 → 10만 회 0.0149). 쌍곡/유클리드 비는 0.357 → 0.099 |
| 상한(원점 쪽 사영) R_max = 5 | 최적해가 유한하다. 시드 50개 중 40개가 평균 상대 왜곡 0.033938로 수렴하고, 반복을 2배로 늘려도 차이가 1.7e-7 이하다 |
| Adam과 "200회 상대 변화 < 1e-6" 규칙만 쓰면 | 진동 중에 멈출 수 있다(평면 격자에서 최적값보다 최대 9.5% 높은 지점). 그러면 ADR 0010의 실패 판정(쌍곡 > 유클리드 × (1 + 1e-3))이 잘못 걸린다. 깊이 7 트리에서는 5만 회까지 멈추지 않았다 |
| 해결 | Adam 뒤에 scipy L-BFGS-B 마무리를 붙인다(ftol 1e-12, 최대 20,000회. 쌍곡은 x = tanh(ρ/2)·w/‖w‖, ρ ∈ [0, R_max]). 모든 사례에서 수 초 안에 수렴했다 |
| R_max에 따른 트리 결과 | R 3 / 5 / 8에서 비 0.441 / 0.225 / 0.115. R 8은 일부 시드가 5만 회까지 수렴하지 않았다. float32의 표현 한계 반지름은 6.21이다 |
| 평면 자료 | 어떤 상한에서도 거짓 쌍곡 이점이 없다(비 0.99–1.00) |
| 척도·곡률 고정 대안 | 쓰지 않는다. 평면 격자에서 거짓 불리가 생긴다(비 1.2–9.2배) |
| 트리 판정 규약(R_max 5와 마무리, 시드 0–4) | 최솟값 비 ≤ 0.3, 중앙값 비 ≤ 0.8, 유클리드 0.1506 ± 0.003, 쌍곡 최솟값 0.0339 ± 0.001(마무리 수렴). 시드 5개 조합 2,118,760개 중 99.9855%가 통과한다. 기준 비는 0.2253 |

권장 수정(사용자 결정 사항):
- 4항의 R_max를 10에서 5로 바꾸고, 수렴 규칙에 L-BFGS-B 마무리 단계를 더해 마무리 값으로 판정한다.
- R_max = 10을 유지하면 최대 20,000회 안에 `converged = false`("보류")가 많이 나올 가능성이 높다. R 8에서 이미 미수렴 시드가 있었다(R 10은 직접 시험하지 않았다).
- S1b의 tree 기준값은 위 규약으로 다시 계산한다.
