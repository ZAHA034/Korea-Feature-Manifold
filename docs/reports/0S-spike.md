## 채택한 판정 규칙 요약

- 사전 고정(ADR 0013 7항): 실데이터 곡률을 계산하기 전에 입력을 커밋한다. 판정 규칙 개정 커밋 29cc115(2026-10-19 18:17 KST), 고정 커밋 b2c7ca2(19:40 KST)

## 결과
### 곡률(0S-3)
- 판정: **조정**(ADR 0013 5항 1). 2항 유효성 점검이 실패했다. |ρ(κ_ex, 1/deg_u + 1/deg_v)| = 0.227, |ρ(κ_ex, log 직선 거리)| = 0.207로 기준 0.1을 넘었다(해안·접경은 0.028). ADR 0013 7항에 따라 이 판정으로 확정한다
- 주 검정(경계 공유 엣지 638개): ρ(κ_ex, s) = 0.102, 단순 p = 0.005, jackknife 최대 p = 0.035(경기도 제외) → 통과
- 편상관 검정: ρ(κ_ex, s | 우회율) = −0.012, 단순 p = 0.614, jackknife 최대 p = 0.963 → 실패. 유효성 점검을 통과했어도 "부분 대응: 곡률의 지형 신호는 통행시간 신호와 같음"이었다
- ρ(κ_ex, 분/km) = 0.822다. 초과 곡률은 대부분 엣지 하나의 우회율이다. 1단계 점검 ρ(분/km, s) = 0.133(p = 0.0004)으로, 통행시간은 지형을 약하게 반영한다
- 섬 링크 ×0.5·×2: 두 검정 모두 결과가 같다(뒤집힘 없음)
- 통근·통학 OD 가중(249개 단위): 주 검정은 통과(ρ 0.176)했고, 편상관은 jackknife p 0.051로 실패했으며, 유효성 점검도 실패했다

### 임베딩과 δ(0S-4)
- 쌍곡 이점: 세 입력 모두 **없음**. 2차원 평균 상대 왜곡 비(쌍곡 / 유클리드)는 `d_time` 250개 0.979, `d_time` 247개 0.979, `d_flow`(주 정규화) 0.913이다. `d_flow`는 대조군 5개 비의 최솟값(0.999)보다 작지만 기준 0.8을 넘는다(대안 정규화 0.941). 최적화 실패·보류·재실행은 0건이고, 판정 재시작은 모두 수렴했다
- 중력모형 이상의 위계: **없음**. δ̄(`d_flow`)는 주 정규화 0.301, 대안 0.301로 대조군 20개(주 0.260–0.264, 대안 0.262–0.267)보다 모두 크다(순위 21/21, 섬 연결 지역 제외도 같음). 관측 통근 거리가 중력 대조군보다 트리에서 더 멀다
- δ 진단: `d_time` 250개는 δ_rel 0.473, δ̄ 0.243이고, 247개도 δ̄ 0.243이다. `d_flow`(주)는 δ_rel 0.722, δ̄ 0.301이다. 섬 연결 지역 제외 부분집합도 거의 같다
- 주의: 대조군은 20% 재표본 뒤 관측 0 패턴을 적용해, 양방향 엣지가 관측보다 약 23% 적다. 성긴 그래프는 폐포 뒤 트리에 가까워 δ̄가 낮게 나오기 쉬우므로, 대조군 δ̄가 아래로 치우쳤을 수 있다. 판정은 사전 규칙대로 "없음"이지만, ADR 0010 6항의 대조군 절차(0 패턴과 재표본의 이중 희소화)는 3단계 전에 다시 볼 필요가 있다
- 대조군 임베딩은 쌍곡 해가 원점으로 수축해(평탄 극한) 비가 약 1.0이다. 관측 `d_flow`의 쌍곡 배치는 중심이 빈 고리(반지름 약 2–5)다
- 최악 쌍: `d_time` 임베딩은 산지 쌍을 과소 추정한다(예: 동해–정선 88.7분 → 14.2분)

## ADR 0009·0010에 줄 시사점
- DESIGN 6.4의 전제 "음곡률(κ ≪ 0) = 병목·자연 장벽"은 엣지 길이가 통행시간이면 성립하지 않는다. 다리 길이 fixture(κ = 0.2 − 0.8/L)처럼 긴 엣지는 κ가 양수 쪽으로 가고, 지형은 κ_ex > 0으로 나타난다(ADR 0013 배경 (4)와 1항). 0S 결과와 무관하게 DESIGN 6.4를 고쳐야 하며, ADR 0009를 채택할 때 반영한다(실데이터 곡률 계산 전에 적음)
- ADR 0009(기준 그래프)에 넣을 문구 제안
  - "엣지 길이가 통행시간인 `G_adj` 위 ORC는 지형·장벽 지표로 쓰지 않는다. 0S에서 기준 차분 곡률 κ_ex는 엣지 우회율과 ρ = 0.82였고, 우회율을 통제하면 지형과의 상관이 사라졌다(편 ρ = −0.012). 장벽 지표가 필요하면 우회율(분/km)이나 지형 측지 거리(PLAN 3-8)를 직접 쓴다."
  - "곡률은 흐름 구조(OD 가중 측도, `G_flow`)와 위상 곡률(엣지 길이 1)을 먼저 검토한다. 실제 그래프에서 κ_ex는 차수(|ρ| 0.23)와 직선 거리(0.21) 효과를 지우지 못했다."
  - "연륙·연도교는 바다를 건너는 도로를 자동 탐지한다(ADR 0013 1항 규칙). 0S에서는 22쌍이었고, 인천대교와 강화–김포는 다각형이 경계를 공유했다. 섬 링크 가정(×0.5·×2)은 곡률 판정을 바꾸지 않았다."
- ADR 0010(임베딩 입력과 비교 기준)에 넣을 문구 제안
  - 4항: "최적화 규약은 ADR 0013 4항(R_max 5, Adam 뒤 L-BFGS-B 마무리, 쌍곡만 재실행)으로 채택한다. 0S 실데이터 14개 입력에서 판정 재시작이 모두 수렴했고 재실행은 0건이었다."
  - 6항: "대조군의 양방향 엣지 수를 관측과 맞춘다. 0S에서는 0 패턴 적용과 20% 재표본이 겹쳐 대조군 엣지가 관측보다 약 23% 적었고, 성긴 대조군의 δ̄가 낮게 치우쳤을 수 있다." 맞추는 방법은 3단계 전에 합성 검증으로 정한다
  - 8항: "쌍곡 Procrustes 정렬과 시나리오 변화량은 쌍곡 이점이 확인된 입력에만 쓴다. 0S에서 `d_time`은 이점이 없었다(왜곡 비 0.979)."
  - 배경: "도시 위계는 통행량 구조에서 더 잘 드러난다"는 가정은 0S 자료에서 확인되지 않았다. 통근·통학 `d_flow`는 `d_time`보다 덜 트리형이었다(δ̄ 0.301 대 0.243). 3단계에서 KTDB OD(전 수단)로 다시 본다

## 판단
- **조정**(ADR 0013 5항). 곡률은 2항 유효성 점검에서 실패했다. 유효성 점검을 통과했어도 "부분 대응: 곡률의 지형 신호는 통행시간 신호와 같음"이었고, 자연 장벽 대응은 보이지 않았다(κ_ex 상위 20개 중 0개)
- PLAN 6.1a에 따라 ADR 0009의 그래프 정의와 엣지 길이를 고친 뒤 2단계에 들어간다. 0S 안에서는 정의를 바꿔 다시 계산하지 않았다(ADR 0013 7항)
- 쌍곡 이점은 `d_time`·`d_flow` 모두 없다. `d_time`에서 없는 것은 실패가 아니다(G24). `d_flow`의 약한 차이(왜곡 비 0.913, 대조군 약 1.0)와 위계 판정의 대조군 문제는 3단계에서 KTDB OD와 고친 대조군 절차로 다시 본다
