## 채택한 판정 규칙 요약
- 곡률(ADR 0013 1·2·5항): κ_ex = κ(`d_sym`) − κ_geo와 평균 경사 s의 단측 Spearman(주 검정)과 우회율을 통제한 편 Spearman(편상관 검정). 둘 다 단순 p와 시도 jackknife p(17개 중 최댓값)가 0.05 미만이어야 "계속"이고, 주 검정만 통과하면 부분 대응이다. 유효성 점검은 차수 항·해안·접경·log 직선 거리와의 |ρ| < 0.1이다. 판정은 조정 → 계속 → 전제 재검토 → 부분 대응 순서로 고르고, 수치를 못 내면 미완이다
- 사전 고정(ADR 0013 7항): 실데이터 곡률을 계산하기 전에 입력을 커밋한다. 고정 커밋: (미기록)
- 임베딩(ADR 0013 4항, ADR 0010 7항): R_max 5, Adam 뒤 L-BFGS-B 마무리. "쌍곡 이점"은 같은 차원 왜곡 비(쌍곡 / 유클리드) ≤ 0.8일 때만 쓴다. `d_flow`는 대조군 비보다도 작아야 한다
