## 채택한 판정 규칙 요약
- 곡률(ADR 0013 1·2·5항): κ_ex = κ(`d_sym`) − κ_geo와 평균 경사 s의 단측 Spearman(주 검정)과 우회율을 통제한 편 Spearman(편상관 검정). 둘 다 단순 p와 시도 jackknife p(17개 중 최댓값)가 0.05 미만이어야 "계속"이고, 주 검정만 통과하면 부분 대응이다. 유효성 점검은 차수 항·해안·접경·log 직선 거리와의 |ρ| < 0.1이다. 판정은 조정 → 계속 → 전제 재검토 → 부분 대응 순서로 고르고, 수치를 못 내면 미완이다
- 사전 고정(ADR 0013 7항): 실데이터 곡률을 계산하기 전에 입력을 커밋한다. 판정 규칙 개정 커밋 29cc115(2026-10-19 18:17 KST), 고정 커밋 b2c7ca2(19:40 KST)
- 임베딩(ADR 0013 4항, ADR 0010 7항): R_max 5, Adam 뒤 L-BFGS-B 마무리. "쌍곡 이점"은 같은 차원 왜곡 비(쌍곡 / 유클리드) ≤ 0.8일 때만 쓴다. `d_flow`는 대조군 비보다도 작아야 한다
- 통행량 거리(ADR 0010 6·7항): "중력모형 이상의 위계"는 `δ̄(d_flow)`가 대조군 20개보다 모두 작고, 대안 정규화와 섬 연결 지역 제외 부분집합에서도 그럴 때만 쓴다

## 결과
### 곡률(0S-3)
- 판정: **조정**(ADR 0013 5항 1). 2항 유효성 점검이 실패했다. |ρ(κ_ex, 1/deg_u + 1/deg_v)| = 0.227, |ρ(κ_ex, log 직선 거리)| = 0.207로 기준 0.1을 넘었다(해안·접경은 0.028). ADR 0013 7항에 따라 이 판정으로 확정한다
- 주 검정(경계 공유 엣지 638개): ρ(κ_ex, s) = 0.102, 단순 p = 0.005, jackknife 최대 p = 0.035(경기도 제외) → 통과
- 편상관 검정: ρ(κ_ex, s | 우회율) = −0.012, 단순 p = 0.614, jackknife 최대 p = 0.963 → 실패. 유효성 점검을 통과했어도 "부분 대응: 곡률의 지형 신호는 통행시간 신호와 같음"이었다
- ρ(κ_ex, 분/km) = 0.822다. 초과 곡률은 대부분 엣지 하나의 우회율이다. 1단계 점검 ρ(분/km, s) = 0.133(p = 0.0004)으로, 통행시간은 지형을 약하게 반영한다
- 섬 링크 ×0.5·×2: 두 검정 모두 결과가 같다(뒤집힘 없음)
- 통근·통학 OD 가중(249개 단위): 주 검정은 통과(ρ 0.176)했고, 편상관은 jackknife p 0.051로 실패했으며, 유효성 점검도 실패했다
- κ_ex 상위 20개: 망 단절 16, 기타 4, 자연 장벽 0, 데이터·설정 문제 0. 1위는 제주시–서귀포시(0.938)
- 보조: 백두대간 선 교차 엣지 검정은 실패(ρ 0.057, p 0.076)했고, h_e와는 음의 상관이다. 옆 엣지 평균 κ_ex는 −0.015로 교차 엣지(0.035)보다 낮다(예상 방향)
